# Third-party design/code references

LittleNet Native is a substantially modified, child-safety-specific Flutter client.

The native social-screen architecture and interaction patterns were accelerated by reviewing:

- `itsezlife/flutter-instagram-offline-first-clone` — Copyright (c) 2024 Emil Zulufov (ezIT). The repository publishes an MIT license with an additional note allowing substantially modified derivative works while prohibiting direct use of the source in its entirety. LittleNet does not vendor that application wholesale; its native feed/stories/reels/search/chat/profile patterns were used as references and reimplemented around LittleNet's own API, safety gates, Parent Mode, moderation and learning flows.

The original license text remains available in the upstream repository. LittleNet's implementation is independently structured for this college project and does not include upstream backend services, Firebase/PowerSync repositories, Instagram branding, or original assets.
